# 🏋️ BD II: Academia

Banco de dados de uma academia, criado para treinar na aula de reposição de Banco de Dados II.

![SQL](https://img.shields.io/badge/SQL-336791?style=for-the-badge&logo=databricks&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=for-the-badge&logo=mysql&logoColor=white)

## Conteúdo

- `academia.sql`: script de criação do banco e das tabelas
- Imagens com o modelo das tabelas (alunos, professores, turmas, matrículas e alocações)
- `instrucoes.md`: enunciado da atividade

## Como rodar

Execute o script `academia.sql` no seu SGBD (por exemplo, MySQL Workbench ou phpMyAdmin).
